# claude_us_sentiment — US equity drawdown-risk monitor

> 🇯🇵 S&P500・ダウの「崩れの兆候」を複数指標から合成し 0–100 の危険度スコアとして毎朝チェック。ザラ場はしきい値監視。

A daily monitor for signs of a breakdown in the **S&P 500 / Dow**. It combines
several indicators into a single **0–100 composite danger score**, posts a
morning report (with charts) as a GitHub Issue, and watches the US session
intraday for threshold breaches.

> **Disclaimer**: The output is an educational heuristic, **not investment
> advice**. Thresholds are rule-of-thumb values and do not predict the market.

## Indicators (6 weighted categories)

| Category | Weight | Indicators | Lead value |
|----------|--------|------------|-----------|
| Valuation | 15% | **Excess CAPE Yield (ECY)** = 1/CAPE − real 10y (primary); Shiller CAPE; PE vs mean | Low (poor timing tool) |
| Trend | 20% | 200-day MA deviation, drawdown from 52w high, below-200MA | Medium |
| Volatility | 20% | VIX level, VIX term structure (VIX vs VIX3M), SKEW, VVIX | High |
| Sentiment | 15% | Put/Call ratio (CBOE total), CNN Fear & Greed | Medium (contrarian) |
| Credit/Macro | 20% | Yield curve (10Y-2Y, 10Y-3M), HY & IG OAS, NFCI, Sahm rule | High |
| Breadth | 10% | Equal-weight ÷ cap-weight ratio (RSP/SPY), % above 200d MA | Medium–High |

See **[`docs/scoring.md`](docs/scoring.md)** for the full normalisation rules.

**Why this mix?** No single indicator is reliable, so categories are combined.
Valuation tells you *how* stretched the market is but not *when* it breaks, so
it is weighted low. Volatility, credit and breadth tend to move early, so they
are weighted higher.

## Danger tiers

| Score | Tier |
|-------|------|
| 0–20 | Calm 🟢 |
| 20–40 | Mild caution 🟢🟡 |
| 40–60 | Caution 🟡 |
| 60–80 | Elevated 🟠 |
| 80–100 | Danger 🔴 |

## Automation

### Daily report — `.github/workflows/daily.yml`
- Weekday mornings 08:00 JST (cron `0 23 * * 0-4` UTC). Manual run supported.
- Computes the score, generates charts, commits them under `charts/<date>/`,
  appends the score to `history/scores.csv`, and opens an Issue with the report
  and charts embedded. Each morning's report is a new Issue (history accumulates).

### Intraday alert — `.github/workflows/intraday.yml`
- Watches the US session and opens an Issue **only when a threshold is hit**:
  - VIX > 20, or +20% vs prior close
  - S&P 500 down > 2% intraday vs prior close
  - VIX term structure inverts (VIX > VIX3M)
  - Composite danger score ≥ 60 (Elevated 🟠 or worse)
- Front-loaded cadence: every 5 min 13:00–15:59 UTC, every 15 min 16:00–21:45 UTC.
- Identical alerts are de-duplicated while the same open Issue exists.
- Note: GitHub-scheduled runs may be delayed/skipped under load.

## Charts (with reference lines)

Generated by matplotlib in the daily job and embedded in the Issue:

1. **Composite danger score trend** — accumulated from `history/scores.csv`.
2. **S&P 500 with 50- and 200-day moving averages.**
3. **Shiller CAPE vs long-run mean (≈17).**
4. **VIX vs long-run average (≈19.5).**

## Setup (FRED API key)

Optional but recommended (falls back to the public FRED CSV if unset).

1. Repo **Settings → Secrets and variables → Actions → New repository secret**
2. Name `FRED_API_KEY`, value = your FRED API key.

> Never commit the key; keep it in Actions secrets only.

## Run locally

Standard library only for scoring (charts need `pip install matplotlib`):

```bash
python market_risk.py                 # auto-fetch -> text
python market_risk.py --report md      # Markdown (issue body)
python market_risk.py --json           # JSON
python market_risk.py --alert          # intraday threshold check (JSON)
python market_risk.py --charts out/    # write chart PNGs
python market_risk.py --manual         # enter values by hand
```

Data sources (all free): FRED (rates/credit/NFCI/Sahm), Yahoo Finance
(prices/VIX/SKEW/VVIX/RSP/SPY), multpl (Shiller CAPE), CNN (Fear & Greed,
best effort). Some are blocked from certain sandboxes; run on Actions or a host
that can reach them.
